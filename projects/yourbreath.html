02 / 개인 기여

연구의 연결과 해석을 맡았습니다

팀 전체의 모델 구현·CNN 학습과 구분한 개인 기여입니다. 후속 PSBI 코드의 세부 업무분장은 별도 확인이 필요합니다.

팀 운영 · 모집 준비

팀장으로 연구 진행을 조율하고, 참여자 모집 문서와 홍보 게시물을 준비했습니다.

설문과 음성의 연결 검토

Google Form 설문 구조와 문항을 정리하고, 설문 기록과 음성 라벨의 매칭 구조를 검토했습니다.

데이터셋 정리

음성 파일명 규칙과 메타데이터, 데이터셋 구성을 정리했습니다.

전처리 · 품질 결과 검토

음성 변환·전처리 출력을 검토하고, 신호대잡음비와 무음 비율의 품질 점검 결과를 정리했습니다.

특징 구조 · 분석 검토

기존 음향 특징과 YAMNet 특징 구조를 분석하고 결측값·이상치 처리 내용을 검토했습니다.

평가 시각화 · 보고·발표

혼동행렬·F1·교차검증 결과를 정리·시각화하고 보고서·발표자료를 작성해 발표했습니다. 공모전 출품을 위한 연구 재정리와 결과 전달에도 참여했습니다.

03 / 팀 연구 흐름

설문과 음성의 연결, 후속 지표 분석

원 연구는 설문·음성을 연결해 전통적 머신러닝과 별도 2D CNN 실험을 진행했습니다. 초기 기획부터 호흡 기반 정량화 지표를 고려했고, 공모전 후속 연구에서 PSBI 분석을 발전시켰습니다.

  1. PSQI 참고 설문 · 음성 수집 →
  2. 기록 · 라벨 매칭 →
  3. 전처리 · 품질 점검 →
  4. 음향 특징 · YAMNet 탐색 →
  5. 전통적 ML / 별도 2D CNN 실험 →
  6. 평가 · 시각화

기존 음향 특징에는 MFCC, Chroma, Spectral Centroid, ZCR이 포함됩니다. YAMNet 기반 음성 표현도 탐색했습니다.

PSQI · 설문 구성의 참고 도구
Pittsburgh Sleep Quality Index를 참고해 설문 문항을 구성하고 주관적 수면 상태 기록을 확보했습니다. 설문 응답은 수집한 호흡 음성과 연결했습니다.
PSBI · 호흡 기반 자체 지표
Pre-Sleep Breathing Index는 호흡 특징으로 수면 전 상태를 정량화하기 위해 연구한 자체 지표입니다. PSQI 설문 점수와 같은 개념이 아닙니다.

팀원 저장소에는 호흡 안정성(Stability), 긴장도(Tension), 준비도(Readiness)와 PSBI 계산·검증을 위한 코드가 포함됩니다. 이는 공모전용 확장 연구의 맥락이며, 아래 원 연구 모델 성능과는 구분합니다.

06 / 연구 문제 해결과 배움

데이터 연결과 평가를 검토한 과정

설문과 음성 기록의 연결

문제 · 설문 기록과 음성 파일이 일치해야 학습 데이터로 활용할 수 있었습니다.

조치 · 파일명 규칙과 메타데이터를 정리하고, 설문 응답과 오디오 라벨의 매칭 구조를 검토했습니다.

배움 · 데이터 수집과 함께 데이터 간 정합성을 확보하는 일이 분석의 신뢰도에 중요함을 배웠습니다.

환경별 오디오 품질 차이

문제 · 생활 환경에서 수집한 음성에는 잡음·무음 구간 등 품질 차이가 있었습니다.

조치 · 노이즈 제거 전후 출력과 SNR, 무음 비율 등 품질검사 결과를 정리했습니다.

배움 · 모델 학습에 앞서 입력 데이터의 품질을 확인하는 과정이 중요함을 배웠습니다.

제한된 데이터에서의 모델 평가

문제 · 수집 데이터 수가 제한되어 성능 수치를 일반화할 때 주의가 필요했습니다.

조치 · 교차검증과 평가 지표를 시각화하고, 모델별 검증 방식과 결과를 구분해 정리했습니다.

배움 · 성능 수치와 함께 평가 조건과 연구의 한계를 설명해야 함을 배웠습니다.
