01 / 프로젝트 소개

일상 사용과 상태 확인,
각자의 목적에 맞게

CareMate는 고령층의 일상 돌봄과 보호자의 상태 확인을 함께 다루는 3인 팀 프로젝트입니다. 고령층이 사용하는 화면과 보호자가 확인하는 화면을 분리하고, 각 역할에 필요한 기능과 정보를 구성했습니다.

2026년 3월부터 6월까지 학기 프로젝트로 진행했습니다. 팀 기술 구성은 React Native·Expo·TypeScript 모바일 앱과 FastAPI·PostgreSQL 백엔드입니다. 저는 모바일 프론트엔드 개발을 주도하고 백엔드/API 연동에 참여했습니다.

03 / 사용자 경험 설계

읽기, 행동, 역할을 구분하는 UI

사용자가 화면을 읽고 다음 행동을 찾을 수 있도록 설계한 기준입니다.

가독성 · 접근성

읽기 쉬운 시각 표현과 간단한 문구를 기준으로, 내용과 조작 대상을 명확하게 전달하도록 설계했습니다.

행동의 위계

화면의 주요 행동과 긴급 행동을 목적에 따라 구분하고, 강조 수준에 차이를 두었습니다.

역할별 탐색 구조

사용자의 역할에 필요한 정보와 행동을 중심으로 화면과 이동 경로를 구성했습니다.

06 / 설계 과제와 배움

설계 선택에서 정리한 관점

확인된 UI 설계 결정을 바탕으로 정리했으며, 사용자 실험이나 효과 측정 결과를 뜻하지 않습니다.

고령층을 위한 정보 단순화

설계 과제
안내가 복잡하면 다음에 무엇을 해야 하는지 파악하기 어려울 수 있다는 점을 고려했습니다.
선택
행동 안내를 간단하게 구성해, 고령층이 읽을 내용과 다음 행동을 연결하는 데 집중했습니다.
배움
정보 단순화는 문장을 줄이는 데서 그치지 않고, 사용자가 해야 할 일을 분명히 전달하는 과정입니다.

음성 대화와 긴급 연락의 다른 목적

설계 과제
일상적으로 시작하는 음성 대화와 긴급 상황의 연락은 구별되는 행동으로 보여줄 필요가 있었습니다.
선택
음성 대화를 눈에 잘 띄는 진입점으로 삼으면서, 긴급 연락은 별도의 시각적 성격을 갖도록 구분했습니다.
배움
중요한 기능을 모두 똑같이 강조하기보다, 사용 맥락에 맞는 구분 기준을 정하는 것이 설계의 핵심입니다.

직접 사용하는 사람과 확인하는 사람

설계 과제
고령층에게는 일상 행동의 안내가, 보호자에게는 돌봄 상태의 요약이 필요했습니다.
선택
고령층 화면은 직접 조작할 기능을 중심으로, 보호자 화면은 복약·일정 등 확인할 정보를 중심으로 구성했습니다.
배움
같은 돌봄 정보를 다뤄도 역할에 따라 보여줄 내용과 우선순위를 달리 정해야 합니다.
