01 / Overview

의류 관리와 재사용을
하나의 앱에서

옷마다 다른 세탁 기호를 확인하고, 보유한 의류와 착용·세탁 일정을 함께 관리할 수 있도록 구성한 의류 관리 플랫폼입니다. 재사용과 업사이클링, 패션 공유를 위한 기능도 함께 다룹니다.

팀 프로젝트는 케어라벨 촬영·직접 선택, 옷장, 착용·세탁 캘린더와 알림, 재사용·업사이클링, 커뮤니티 기능으로 구성됩니다.

아래 기능과 화면은 팀 전체의 결과물입니다. 제 개인 기여는 별도의 담당 역할에서 구분해 소개합니다.

02 / My Contributions

직접 담당한 기능과 설계

화면 개발부터 서비스 연동, 모델 개발까지 개인 기여를 정리했습니다.

01

로컬 · 소셜 인증

로컬 인증과 카카오·Google 로그인 기능을 개발했습니다.

02

홈 · 옷장 · 캘린더

홈·옷장·캘린더 화면을 개발하고, 카메라·갤러리를 통한 이미지 입력을 연동했습니다.

03

나의 숲 구조 · UI

게이미피케이션을 적용한 ‘나의 숲’ 탭의 전체 구조와 UI를 설계했습니다.

04

재활용 · 업사이클링

키워드 기반 YouTube 영상 검색과 즐겨찾기를 포함한 재활용·업사이클링 페이지를 개발했습니다.

05

백엔드 · DB 연동

백엔드 일부 구현과 앱·서버·데이터베이스 연동에 참여했습니다.

06

세탁 기호 인식 모델

YOLOv8 기반 케어라벨 세탁 기호 탐지 모델을 개발하고, 한국 기준에 맞춰 학습용 기호를 직접 라벨링했습니다.

‘나의 숲’의 담당 범위는 전체 구조·UI 설계이며, 게임 로직 전체의 구현을 의미하지 않습니다. EfficientNet-B0 의류 분석, Gemini API 연동, 커뮤니티는 팀 수준의 기능입니다.

Problem Solving

개발 과정에서 마주한 문제와 배움

한국 케어라벨 학습 데이터 확보

문제
한국 의류의 세탁 기호를 학습하기 위한 케어라벨 데이터가 부족했습니다.
행동
주변의 도움을 받아 실제 의류 라벨 사진을 수집하고, 한국 기준에 맞춰 기호를 직접 라벨링했습니다.
배움
사진 수집부터 기호 라벨링까지 머신러닝 학습 데이터를 준비하는 흐름을 익혔습니다.

Git 협업 파일 관리

문제
업로드된 미디어, 로컬 설정, 개발용 데이터가 의도치 않게 공유되어 환경 관련 혼선이 생겼습니다.
행동
팀과 함께 Git 추적 대상과 제외할 파일을 정리하고, 파일 관리 방식을 개선해 환경 관련 혼선을 줄였습니다.
배움
공유할 소스와 로컬 파일을 구분하고 추적 상태를 함께 확인해야 함을 배웠습니다.

React Native 화면 일관성

문제
AI로 생성한 레이아웃이 시뮬레이터에서 의도한 화면과 다르게 나타났습니다.
행동
시뮬레이터 화면을 확인하며 간격, 정렬, 글자 크기와 색상을 직접 디버깅하고 조정했습니다.
배움
생성된 코드도 실제 화면에서 검토하고 수동으로 다듬어야 시각적 일관성을 높일 수 있음을 배웠습니다.
