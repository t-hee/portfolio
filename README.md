# 한태희 개발자 포트폴리오

프론트엔드·모바일 개발과 API·DB·AI·IoT 연동 경험을 소개하는 정적 포트폴리오입니다. 홈페이지와 여섯 프로젝트 상세 페이지의 1차 구현을 완료했습니다. 최종 사실 검토, 실제 이미지 교체, 브라우저 QA와 공개 배포는 진행 전입니다.

## 기술 구성

HTML5, 공유 CSS, 바닐라 JavaScript만 사용합니다. 프레임워크, 빌드 도구, 패키지 설치나 백엔드가 필요하지 않습니다. 모든 페이지는 같은 흰색·네이비 디자인과 반응형 메뉴를 공유합니다.

## 디렉터리 구조

```text
portfolio/
├── index.html                   # 소개·프로젝트·기술·수상·연락처
├── css/style.css                # 홈페이지와 상세 페이지 공유 스타일
├── js/main.js                   # 모바일 메뉴·현재 섹션·헤더 높이 처리
├── projects/
│   ├── rewear.html              # ReWear
│   ├── meetfit.html             # MeetFit
│   ├── caremate.html            # CareMate
│   ├── wallguard.html           # WallGuard
│   ├── campuscare.html          # CampusCare
│   └── yourbreath.html          # 너의 숨소리
├── assets/
│   ├── images/                  # 승인된 실제 이미지용 공간
│   └── docs/                    # 공개 승인 문서용 공간
├── docs/
│   ├── FINAL_REVIEW_TODO.md     # 우선순위별 최종 검토 목록
│   ├── SCREENSHOT_TODO.md       # 프로젝트별 화면·연구 도표 준비
│   ├── REWEAR_BRIEF.md
│   └── WALLGUARD_BRIEF.md
├── AGENTS.md                   # 작업 규칙
├── PORTFOLIO_SPEC.md            # 승인된 최초 기획·디자인 기준
├── PROJECT_FACTS.md             # 검증 사실·검증 범위·미확인 항목
├── .gitignore

```

`PORTFOLIO_SPEC.md`의 초기 구현 상태·예정 경로 설명은 기획 당시 기록입니다. 현재 구현 상태는 이 문서와 최종 검토 목록을, 프로젝트 사실은 `PROJECT_FACTS.md`를 기준으로 확인합니다.

## 로컬 미리보기

저장소 루트에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 5500 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:5500/>을 열고 홈페이지의 여섯 상세 링크를 확인합니다. 종료는 `Ctrl+C`입니다. 모바일 폭, 키보드 탐색, 메뉴 열기·닫기와 Escape, 고정 헤더 아래 앵커 위치, 모션 감소 설정은 실제 브라우저에서 별도 점검해야 합니다. 정적 경로 검사 통과만으로 화면·접근성 검증이 완료되지는 않습니다.

## GitHub Pages 배포 계획

최종 사실·권한·개인정보 검토와 QA 후 소유자의 배포 승인에 따라 GitHub Pages의 `main` 브랜치 루트 배포를 설정할 계획입니다. 현재 공개 배포나 공개 URL 검증이 완료되었다고 주장하지 않습니다. HTML·CSS·JS는 저장소 하위 경로에서도 동작하도록 상대 경로를 사용합니다. 배포 후 HTTPS, 실제 공개 URL, 데스크톱·모바일 메뉴와 여섯 상세 페이지·정적 자산 경로를 확인합니다. 무료 사이트 검증 이후에만 선택적으로 도메인을 검토합니다.

## 개인정보와 기여 표기

- 검증되지 않은 날짜, 성과, 연락처, 배포·테스트 완료 주장을 추가하지 않습니다. 공개 연락처·프로필·이력서는 소유자 확인 후 연결합니다.
- 개인 구현과 팀 전체 기능·연구 결과를 구분합니다. ReWear·CareMate는 팀원 소유 저장소이며, 공개 링크 승인 확인 전까지 사이트의 소스 링크를 보류합니다. URL은 내부 사실·검토 문서에 보존합니다.
- MeetFit·WallGuard·CampusCare의 비공개 소스는 공개 결정과 비밀정보 검토 전까지 연결하지 않습니다. 너의 숨소리는 참여자 개인정보와 공동 작업자 권한 확인이 필요합니다. 다른 사람의 저장소나 공개 설정은 변경하지 않습니다.
- 비밀키, 인증 정보, `.env`, 로컬 DB, 원시 연구 데이터, 참여자 식별 정보와 개인 연락처를 포함하지 않습니다. 문서도 공개 저장소에 포함될 수 있으므로 민감한 자료를 넣지 않습니다.
- 실제 프로젝트의 공개 승인 이미지·도표만 사용합니다. 현재 중립 플레이스홀더는 최종 캡처 단계에서 교체합니다. ReWear의 로컬 원본 `home.png`, `closet.png`, `lounge.png`는 정확한 경로로 Git에서 제외되어 있으며, 사이트에서 참조하지 않습니다. 개인정보·공유 권한 검토 전까지 원본을 추가하지 않습니다.
- 남은 사실 확인·권한 결정·시각 QA·배포 작업은 [최종 검토 목록](docs/FINAL_REVIEW_TODO.md), 화면별 캡처는 [이미지 준비 목록](docs/SCREENSHOT_TODO.md)에서 관리합니다.
